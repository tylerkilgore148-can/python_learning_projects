# two-level login checker

beginner python project simulating 2 factor authentication for login.

## what it does 

- asks for first pass code and identifies the user
- asks for a second pass code to confirm access
- allows user to pull a report
### how to run

python3 personal_learning_projects1.py

### what i practiced

- input() and string comp
- if/elif/else
- nested if statements

## next steps
